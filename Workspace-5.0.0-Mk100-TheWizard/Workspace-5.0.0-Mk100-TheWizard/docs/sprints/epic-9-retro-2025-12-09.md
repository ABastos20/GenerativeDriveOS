### Challenges & Growth Areas

Bob (Scrum Master): "Now let's talk about struggles. Where did Epic 9 challenge us?"

#### 1. Complexity of Multi-Human Voting UX

Elena (Junior Dev): "Designing the voting UI was tricky. How do we show weighted votes without confusing users?"

Alice (Product Owner): "We solved it with transparency. Show both raw vote count AND weighted score. Users can see the math."

Dana (QA Engineer): "Testing voting edge cases was complex - what if two experts tie? What if quorum is 49.9%?"

Charlie (Senior Dev): "We handled it with clear rules: ties go to higher authority, quorum is rounded up. No edge case is undefined."

**Outcome:** Complexity managed through transparency and explicit rules.

#### 2. Constitutional Validation Performance

Charlie (Senior Dev): "Story 9-4's constitutional validation runs on every proposal creation and every vote. For large constitution files, that could be slow."

Elena (Junior Dev): "How did we optimize?"

Charlie (Senior Dev): "Cached constitution in memory, only re-parse on amendments. And constitutional validation is fast - regex matching on red lines."

**Outcome:** Performance concern addressed with caching.

#### 3. Trust Score Bootstrapping

Dana (QA Engineer): "New users start with zero trust. How do they build trust to participate?"

Alice (Product Owner): "We allow Observer role by default. They can view everything, but can't vote until they demonstrate expertise."

Winston (Architect): "And trust scores can be manually seeded by Owners for domain experts joining the system."

**Outcome:** Bootstrapping handled with Observer role and manual seeding.

### Key Insights & Learnings

Bob (Scrum Master): "Let me synthesize the patterns..."

#### Governance Insights

1. **Roles Prevent Chaos:** Clear authority structures (Owner → Admin → Contributor → Observer) enable scalable governance
2. **Trust-Weighting is Fair:** Expertise should matter - domain experts' votes carry more weight
3. **Constitutional Constraints Protect Core Values:** Democracy without guardrails is mob rule
4. **Transparency Builds Trust:** Users trust systems they can inspect and audit
5. **Escalation Prevents Deadlock:** Well-designed escalation rules keep governance moving

Winston (Architect): "That third insight - constitutional constraints - is crucial. We're not building pure democracy. We're building constitutional democracy."

Alice (Product Owner): "And insight 4 - transparency - is why the dashboard is so important. If users can't see governance, they won't trust it."

#### Technical Insights

1. **Permission Gating via Decorators:** `@require_permission()` is clean and reusable
2. **JSONB for Trust Scores:** `trust_scores: Dict[domain, score]` is flexible and queryable
3. **WebSocket for Real-Time Dashboard:** Governance changes feel instant
4. **Audit Trail is Non-Negotiable:** Every role change, every vote, every amendment - logged
