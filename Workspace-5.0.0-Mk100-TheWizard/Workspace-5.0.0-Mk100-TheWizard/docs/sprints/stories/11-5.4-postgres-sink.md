### AC 2: PostgresSink Implementation

**Given** events need database persistence
**When** the sink receives an event
**Then** it inserts into PostgreSQL

**Implementation:**
```python
class PostgresSink:
    def __init__(self, session_factory):
        self._session_factory = session_factory

    def handle_event(self, event: EpistemicEvent) -> None:
        session = self._session_factory()
        try:
            model = EpistemicEventModel(
                id=event.event_id,
                event_type=event.event_type.value,
                knowledge_unit_id=event.knowledge_unit_id,
                timestamp=event.timestamp,
                payload=event.to_json_schema(),
            )
            session.add(model)
            session.commit()
        except Exception as e:
            session.rollback()
            logger.warning("postgres_sink_failed", error=str(e))
        finally:
            session.close()
```

- [x] Create `PostgresSink` in `audit_sinks.py`
- [x] Accept session_factory for dependency injection
- [x] Graceful error handling (rollback, warn, continue)

### AC 5: Query Support (Optional)

**Given** forensic timeline queries are useful
**When** InMemorySink is not sufficient
**Then** provide DB-backed query methods

**Implementation:**
```python
class PostgresAuditQueryService:
    def get_forensic_timeline(
        self, 
        knowledge_unit_id: UUID,
        start_time: datetime = None,
        end_time: datetime = None,
    ) -> list[EpistemicEvent]:
        query = session.query(EpistemicEventModel).filter(
            EpistemicEventModel.knowledge_unit_id == knowledge_unit_id
        )
        if start_time:
            query = query.filter(EpistemicEventModel.timestamp >= start_time)
        if end_time:
            query = query.filter(EpistemicEventModel.timestamp <= end_time)
        return [self._to_event(m) for m in query.all()]
```
