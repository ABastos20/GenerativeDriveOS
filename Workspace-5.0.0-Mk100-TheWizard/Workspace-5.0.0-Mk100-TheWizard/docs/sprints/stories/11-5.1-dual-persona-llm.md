> *"Replace heuristic persona logic with actual LLM calls."*

---

## Story

As a system architect,
I want **the Analyst and Adversary personas to use real LLM calls**,
so that **dual-persona arbitration produces genuinely adversarial evaluation, not placeholder heuristics**.

---

## Context

Story 11-5 implemented Dual-Persona Arbitration (AC3) with placeholder heuristic logic in `arbitration.py:178-259`. The mathematical rule is correct:

```
Promotion(i) = allowed ⟺ f_A(i) = 1 ∧ f_D(i) = 1
```

But `f_A` (Analyst) and `f_D` (Adversary) currently use keyword matching instead of actual LLM reasoning.

---

## Acceptance Criteria

### AC 1: Analyst Persona LLM Integration

**Given** a knowledge item requires promotion evaluation
**When** the Analyst persona evaluates it
**Then** it calls the LLM provider with a coherence/logic prompt

**Implementation:**
- [x] `analyst_llm_call(i)` uses existing provider interface
- [x] Prompt focuses on: coherence, logic, contradiction detection
- [x] Returns `(bool, str)` - verdict and explanation
- [x] Pure function - no side effects

---

### AC 2: Adversary Persona LLM Integration

**Given** a knowledge item requires promotion evaluation
**When** the Adversary persona evaluates it
**Then** it calls the LLM provider with an adversarial probe prompt

**Implementation:**
- [x] `adversary_llm_call(i)` uses same provider, different prompt
- [x] Prompt focuses on: exploit search, jailbreak patterns, epistemic attack surface
- [x] Higher temperature for creative attack discovery
- [x] Returns `(bool, str)` - verdict and explanation

---

### AC 3: Arbitration Rule Enforcement

**Given** both personas have evaluated
**When** determining promotion eligibility
**Then** promotion allowed only if BOTH pass

**Implementation:**
- [x] `promote(i) = True ↔ analyst_ok ∧ adversary_ok`
- [x] Freeze on disagreement (one pass, one fail)
- [x] Hard deny on both fail

---

### AC 4: Audit Safety

**Given** LLM calls produce verbose outputs
**When** logging to epistemic audit
**Then** no raw prompts or responses are stored

**Implementation:**
- [x] Log only: `{event_type, reason, persona_verdicts}`
- [x] No `raw_prompt`, no `llm_response` in audit events
- [x] Verdicts condensed to tags: `"analyst_pass"`, `"adversary_fail"`

---

### AC 5: Graceful Degradation

**Given** LLM provider is unavailable
**When** arbitration is requested
**Then** system safely defaults to FREEZE (not crash)

**Implementation:**
- [x] Provider failure → return FREEZE with reason
- [x] Log warning to observability layer
- [x] Never raise exception to caller
