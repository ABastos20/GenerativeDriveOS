## Acceptance Criteria

### AC 1: StdoutJsonSink Implementation

**Given** an epistemic event is logged
**When** StdoutJsonSink is active
**Then** event is written as single JSON line to stdout

**Implementation:**
```python
import structlog

logger = structlog.get_logger("jarvis.epistemic")

class StdoutJsonSink:
    def __init__(self, redact_content: bool = True):
        self.redact_content = redact_content
    
    def handle_event(self, event: EpistemicEvent) -> None:
        data = event.to_json_schema()
        if self.redact_content:
            data = self._redact(data)
        logger.info("epistemic_event", **data)
    
    def _redact(self, data: dict) -> dict:
        data.pop("raw_prompt", None)
        data.pop("document_text", None)
        data.pop("context", None)
        return data
```

- [x] Create `StdoutJsonSink` in `audit_sinks.py`
- [x] Use structlog for JSON formatting

### AC 2: Content Redaction (Security)

**Given** events may contain sensitive data
**When** logging to external systems
**Then** PII and raw content are stripped

**Safe to log:**
- `event_id`, `event_type`, `timestamp`
- `knowledge_unit_id`, `tier`, `trust_score`
- `reason` (short tag, not full text)
- `authorized_by`, `requester`

**Never log:**
- Raw document text
- LLM prompts/responses
- PII fields

- [x] Implement `_redact()` method
- [x] Default `redact_content=True`
- [x] Log only safe fields

### AC 5: Configuration

**Given** different environments need different sinks
**When** configuring the audit log
**Then** use environment variables

**Implementation:**
```python
def create_audit_log_from_env() -> EpistemicAuditLog:
    config = os.getenv("EPISTEMIC_AUDIT_SINKS", "memory")
    sinks = []
    if "memory" in config:
        sinks.append(InMemorySink())
    if "stdout" in config:
        sinks.append(StdoutJsonSink())
    return EpistemicAuditLog(sinks=sinks)
```

## Observability Integration Guide

### Graylog (Docker Sidecar)

```yaml
# docker-compose.yml
services:
  jarvis:
    environment:
      EPISTEMIC_AUDIT_SINKS: memory,stdout
    logging:
      driver: gelf
      options:
        gelf-address: "udp://graylog:12201"
```

### ELK (Filebeat)

```yaml
# filebeat.yml
filebeat.inputs:
  - type: container
    paths:
      - '/var/lib/docker/containers/*/*.log'
    json.keys_under_root: true
    json.add_error_key: true

output.elasticsearch:
  hosts: ["elasticsearch:9200"]
  index: "jarvis-epistemic-%{+yyyy.MM.dd}"
```

### Example Queries

```
# Graylog: Find all usage violations
event_type:usage_violation AND tier:K3

# ELK: Promotions in last hour
event_type:promotion AND @timestamp:[now-1h TO now]
```
