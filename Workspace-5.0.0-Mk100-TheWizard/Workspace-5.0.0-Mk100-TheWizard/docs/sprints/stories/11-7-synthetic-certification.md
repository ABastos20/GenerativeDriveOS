## Acceptance Criteria

### AC 1: Synthetic Origin Tagging (Mandatory)

**Given** content is generated by the system
**When** stored in knowledge base
**Then** synthetic origin is clearly tagged

**All generated outputs must declare:**
- `origin = synthetic`
- `generator_id`
- `model_version`
- `prompt_hash`

**Implementation:**
- [x] No synthetic object may enter Tier 2 via ingestion
- [x] Enforced at:
  - BMAD output
  - Simulation engine
  - Forecast modules
- [x] Synthetic tagging in `src/jarvis/simulation/tagging.py`
- [x] Automated detection of synthetic content
- [x] Validation before storage in Epistemic Ledger

---

### AC 2: Simulation Certificate

**Given** simulation produces results
**When** results are stored
**Then** certificate accompanies all simulation outputs

**SimulationCertificate Schema:**
```python
@dataclass
class SimulationCertificate:
    sim_id: str
    model_id: str
    assumptions: list[str]
    boundary_conditions: dict
    confidence_interval: tuple[float, float]
    hazard_flags: list[str]
```

**Implementation:**
- [x] `src/jarvis/simulation/certifier.py` created
- [x] Every simulation result must carry certificate
- [x] Stored in Epistemic Ledger as: `class = "synthetic_certified"`
- [x] Certificate includes:
  - Simulation ID
  - Model/algorithm used
  - Input assumptions
  - Boundary conditions
  - Confidence intervals
  - Known hazards/limitations

---

### AC 3: Synthetic → Evidence Firewall

**Given** attempt to promote synthetic content
**When** promotion is requested
**Then** strict firewall rules enforced

**Forbidden Transitions:**

| From      | To               | Allowed |
| --------- | ---------------- | ------- |
| Synthetic | Primary Evidence | ❌ Never |
| Synthetic | Provisional (T1) | ✅ With label |
| Synthetic | Governance Input | ❌ Blocked |

**Implementation:**
- [x] `src/jarvis/simulation/firewall.py` created
- [x] Attempted promotion auto-triggers:
  - C-IDS alert
  - Governance audit entry
- [x] Hard firewall rules enforced
- [x] No bypass mechanism except governance override
- [x] Full audit trail for all promotion attempts

---

### AC 4: Simulation Replay & Determinism Control

**Given** simulation can be replayed
**When** replay occurs
**Then** deterministic results validated

**Implementation:**
- [x] `src/jarvis/simulation/replay_guard.py` created
- [x] Simulation replays must:
  - Rehydrate identical results for same seed
  - Store stochastic drift explicitly
- [x] Certified as: `deterministic | stochastic`
- [x] Replay validation:
  - Hash comparison for deterministic
  - Statistical bounds for stochastic
- [x] Drift detection and logging

---

### AC 5: Forecast vs Fact Firewall

**Given** content predicts future
**When** classified
**Then** tagged as forecast, not fact

**Anything predicting future must be tagged:**
```
knowledge_class = "forecast"
```

**Forecasts:**
- Cannot update beliefs directly
- Only influence *scenario layers*
- Must carry confidence intervals
- Require uncertainty quantification

**Implementation:**
- [x] `src/jarvis/forecasting/classifier.py` created
- [x] Automatic forecast detection
- [x] Scenario layer separation
- [x] Confidence interval enforcement
- [x] Uncertainty quantification required

---

### AC 6: Recursive Self-Training Block

**Given** synthetic output exists
**When** attempting to use for training
**Then** self-training is blocked

**Synthetic output cannot be:**
- Re-ingested as Tier-2
- Used as training data
- Used as trust reference

**Unless:**
- Human-signed governance waiver exists
- Simulation lineage passes audit

**Implementation:**
- [x] `src/jarvis/simulation/self_training_guard.py` created
- [x] Recursive ingestion detection
- [x] Training data validation
- [x] Governance waiver system
- [x] Lineage audit trail
- [x] Automatic blocking with alerts
