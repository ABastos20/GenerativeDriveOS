# Product Requirements Document (PRD) — JARVIS System

## Vision
Build a self-grown, modular assistant and AI advisor (JARVIS) integrating multiple APIs and local LLMs for automation, decision support, and orchestration.

## Goals
- Modular agentic architecture
- Easy integration of APIs and LLMs
- Orchestration and automation for workflows
- Clear documentation and test harnesses

## Functional Requirements
- Agent files for orchestration, API, and LLM modules
- Integration config for endpoints, keys, and models
- PowerShell scripts for initialization and orchestration
- Sprint/project board for tracking

## Non-Functional Requirements
- Extensible and maintainable codebase
- Secure handling of API keys and credentials
- Fast setup and onboarding

## Acceptance Criteria
- System can activate and switch agents
- APIs and LLMs are configurable and testable
- Orchestration script launches integrations
- Documentation covers setup, activation, and usage

## Out of Scope
- UI/Frontend (for now)
- Cloud deployment (for now)

## Next Steps
- Finalize integration config
- Implement orchestration logic
- Add test harness
- Document agent activation and switching
