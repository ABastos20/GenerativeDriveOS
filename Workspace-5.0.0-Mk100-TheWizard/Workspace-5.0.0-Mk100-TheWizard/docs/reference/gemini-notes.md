# Gemini CLI Assistant

Hello! I am the Gemini CLI Assistant, an AI agent designed to help you with software engineering tasks directly from your command-line interface.

## My Capabilities:

*   **Code Understanding & Modification:** I can read, analyze, and modify code, adhering to existing project conventions, style, and structure.
*   **Bug Fixing:** I can identify and fix bugs in your codebase.
*   **Feature Development:** I can implement new features based on your requirements.
*   **Refactoring:** I can refactor code to improve its quality, readability, and maintainability.
*   **Testing:** I can write and execute tests to verify changes and ensure code quality.
*   **Documentation:** I can help create and update documentation.
*   **Project Navigation:** I can explore your project's file structure and content to understand the context.
*   **Tool Usage:** I can utilize a variety of tools to perform tasks, including:
    *   `run_shell_command`: Execute shell commands.
    *   `read_file`: Read file contents.
    *   `write_file`: Write content to files.
    *   `replace`: Perform text replacements in files.
    *   `list_directory`: List directory contents.
    *   `search_file_content`: Search for patterns within file content.
    *   `glob`: Find files matching glob patterns.
    *   `codebase_investigator`: For deep codebase analysis.
    *   `write_todos`: To manage and track complex tasks.
    *   `browser_*`: A suite of tools to interact with web pages (navigate, click, type, etc.).
    *   `google_web_search`: To perform web searches.
    *   `get_library_docs`, `resolve_library_id`: To fetch library documentation.
    *   `sequentialthinking`: For complex problem-solving.

## How I Can Help You:

*   **Solve problems:** Describe a bug or a task, and I will work to resolve it.
*   **Implement features:** Provide feature specifications, and I will implement them following your project's conventions.
*   **Refactor code:** Point out areas for improvement, and I will refactor the code.
*   **Answer questions:** Ask me about your codebase or general programming concepts, and I will do my best to provide accurate information.
*   **Automate tasks:** I can help automate repetitive development tasks.

Please provide me with a clear and concise request, and I will do my best to assist you!
